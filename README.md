# R. Naveen — Data Analyst Portfolio & Analytics Command Center

A modern, high-performance **Analytics Dashboard & Developer Portfolio** built strictly from verified resume data for **R. Naveen** (Data Analyst).

Designed with dark glassmorphism, subtle grid lines, interactive formula inspectors, realistic project metric visualizations, and an in-browser interactive SQL query sandbox.

---

## 🚀 Live Tech Stack
- **Framework:** React 19 + TypeScript + Vite 8
- **Styling:** Tailwind CSS + Vanilla CSS Glassmorphism
- **Design Aesthetic:** Dark Glass Panels, Glowing Borders, Subtle Background Data Grid, Minimal Neon
- **Icons & Visuals:** `lucide-react` + Custom SVG Brand Icons
- **Data Integrity:** 100% authentic resume details (zero fabricated statistics, fake testimonials, or placeholder company logos)

## 🛠️ Installation & Local Setup

### 1. Prerequisites
- **Node.js:** v20.18+ or later
- **npm:** v10+

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
The site will be live at `http://localhost:5173/`.

### 4. Production Build & Preview
```bash
npm run build
npm run preview
```

## 📄 Replacing the Resume PDF
To link your updated physical resume:
- Replace the file located at [`public/resume.pdf`](file:///d:/portfolio/public/resume.pdf) with your latest PDF file.
- All "Download Resume" buttons on the portfolio are pre-wired to download this asset directly.
